# Slack ITニュース要約Bot 企画書

作成日: 2026年7月13日
ステータス: 社内承認待ち

---

## 1. 目的・背景

チーム内でITトレンド・技術動向の情報収集を効率化するため、複数の情報源（技術記事・ニュースサイト）から話題性の高い記事を自動選定し、要約付きでSlackに週次配信するBotを構築する。

- 手動でのキャッチアップ時間を削減する
- ソースを横断して「話題になっているもの」を機械的にピックアップする
- 要約により、忙しいメンバーでも短時間で概要を把握できるようにする

---

## 2. 要件サマリー

| 項目 | 内容 |
|---|---|
| 投稿頻度 | 週1回（毎週月曜9:00 JST） |
| 投稿本数 | 基本3本。AIが「面白い」と判定した候補が多ければ増量（上限の目安: 10本） |
| 情報源 | Qiita, Zenn, Hacker News, Publickey, ITmedia NEWS, CNET Japan, TechCrunch（英語）＋ Claude API Web検索（金融・製造業のIT/DX動向、海外大手AI企業/GAFAMの最新動向） |
| 要約方針 | 高性能モデル（Web検索ツール有効）で候補選定・重複除外 → 軽量モデルでやや詳しめ要約（3〜5文＋背景） |
| 投稿先 | Slack（Bot経由）。将来的にはQ&A Bot化も見据える |

情報源の選定経緯: 当初案にあったTechCrunch Japanは日本事業終了の影響でフィード配信が不安定だったため除外し、代替としてCNET JapanとTechCrunch本体（英語）を追加した（英語記事は要約時に日本語へ変換する）。

さらに、既存の情報源はいずれも汎用IT系メディアで銀行・保険・製造業等の業界動向をカバーしていないため、候補選定モデル（Sonnet 5）にWeb検索ツールを持たせ、①メガバンク・大手保険会社を中心とした金融業界のIT×DX動向、②大手製造業のIT×DX動向、③海外の大手AI企業・GAFAMの最新動向、を都度検索・発掘する方式を追加した（いずれも「必ず入れる枠」ではなく、質の高い候補が無ければ0件でよい）。検索クエリは固定文言ではなくモデルに自律的に組み立てさせる（大枠の方針のみプロンプトで指定）。ドメインのallowlist制限は新規メディアの取りこぼしにつながるため行わず、明らかに低品質なサイトが混入した場合のみ`blocked_domains`で個別除外する運用とする。

## 3. 想定コスト

| 項目 | 想定コスト |
|---|---|
| Claude API利用料 | 月$3〜5程度を想定（週1回、候補選定30〜50件＋Web検索数回のスクリーニングをSonnet 5、記事本文要約最大10本分をHaiku 4.5で実施。Web検索は$10/1,000回、モデル料金はSonnet 5が$3/$15・Haiku 4.5が$1/$5 per MTok） |
| GitHub Actions | 無料枠内で完結（週1回・数分の実行） |
| Slack | 追加コストなし（既存ワークスペースのBot追加のみ） |

## 4. 社内承認が必要な事項

以下は本Botを稼働させる上で必須だが、社内の許可・手続きが必要なため現時点では未着手。

- [ ] Slack Appの新規作成・ワークスペースへのインストール許可
- [ ] Bot投稿用チャンネルの確定（新規作成 or 既存チャンネル利用）
- [ ] Claude API（Anthropic）の利用契約・APIキー発行
- [ ] GitHub Actions上でのSecrets登録・外部API呼び出しの許可

→ 承認が下りるまでは、設計・実装（ローカルでのロジック確認まで）を先行して進める。
